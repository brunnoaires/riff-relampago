# Músicas da casa

As músicas desta pasta aparecem no menu do jogo para todo mundo que abrir o site. Só quem pode mexer neste repositório consegue colocar músicas aqui.

Coloque só músicas suas ou com licença livre: o site e o repositório são públicos.

## Como adicionar

1. No GitHub, abra esta pasta `musicas`.
2. Clique em **Add file > Upload files**.
3. Arraste um pacote `.sng` ou a pasta inteira da música (com `notes.chart` ou `notes.mid`, o áudio `song.ogg` / `guitar.ogg` e o `song.ini`).
4. Clique em **Commit changes**.

Em um ou dois minutos a lista `lista.json` é atualizada sozinha e a música aparece no menu. Para tirar uma música, apague o arquivo ou a pasta dela.

O GitHub aceita arquivos de até 25 MB pelo site. Áudio em OGG ou OPUS fica bem menor que WAV.
